# ADR-0002: 지도 매장 화면 미리보기 — 관찰자 전용 뷰 신설

- **상태**: Accepted
- **날짜**: 2026-08-10
- **관련 문서**: `BUSINESS_RULES.md` §2.7, §2.8 (게이트 예외 조항)

## 맥락

ADR-0001로 좌석 선택이 방 입장의 전제조건이 되면서, 지도에서 매장을 가볍게 미리 살펴보는
경로가 그 게이트에 막히지 않아야 한다는 요구가 나왔다. 기존 §2.7에는 이미 "매장 상세
바텀시트"(HOT/실시간 별점/매장채팅/좌석 4탭, 비참여자도 열람 가능)가 문서화돼 있었는데,
이번에 사용자가 말한 "매장 정보만 보여주는 관찰자 뷰"가 그것과 같은 화면인지 다른 화면인지
확인이 필요했다.

## 결정

지도에서 매장을 탭하면, 기존 §2.7의 4탭 상세 바텀시트와는 **별개로** 방 화면의 "매장" 탭
컴포넌트를 그대로 재사용한 미리보기 바텀시트도 띄운다. 참여자로 집계되지 않고 좌석도
배정되지 않으며, 어떤 리액션·채팅에도 영향을 줄 수 없는 순수 관찰자(read-only) 뷰다.
Seating 도메인(§2.8) "좌석 선택 = 방 입장" 게이트의 예외 대상이다.

## 버린 대안

- **기존 §2.7 4탭 상세 바텀시트로 통합** — 사용자가 "별개의 새 화면(추가)"라고 명시적으로
  확정하여 폐기

## 미확정 (열린 질문)

- 트리거 UI/배치 (기존 4탭 상세와 어떻게 구분해서 노출할지)
- "매장" 탭 UI 외에 추가되는 1~2개 UI 요소의 구체 내용
